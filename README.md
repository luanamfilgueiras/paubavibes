# 🏖️ Paúba Vibes — Locação de Casas por Temporada

Website institucional e vitrine de alta conversão para locação de casas por temporada na paradisíaca praia de **Paúba (São Sebastião - SP)**.

---

## 🌟 Funcionalidades do Projeto

- **Vitrine Dinâmica de Imóveis**: Cards com fotos reais, comodidades, badges de hóspedes/quartos e valores a partir de R$ 400/diária.
- **Carrossel & Lightbox Modal (10+ fotos)**: Visualizador de fotos em tela cheia com navegação por gestos (*swipe* no celular), miniaturas e botões direcionais.
- **Reserva Direta via WhatsApp**: Botões que geram automaticamente links `wa.me` com o número e a mensagem pré-preenchida com o nome da casa escolhida.
- **Design System Coastal Luxury**: Estética praiana sofisticada, paleta de cores exclusiva, microanimações e mobile-first.
- **Seções Institucionais**: Guia "Por que Paúba?", Perguntas Frequentes (FAQ accordion) e botão flutuante de atendimento.
- **SEO & Social Share**: Meta tags OpenGraph configuradas para compartilhamento com pré-visualização no WhatsApp e redes sociais.

---

## 💻 Tecnologias

- **Vite** — Build tool ultrarrápido
- **HTML5 Semântico** & **JavaScript ES Modules**
- **Vanilla CSS3** com CSS Custom Properties (sem dependências pesadas de frameworks)

---

## 🚀 Como Rodar o Projeto

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor local
npm run dev

# 3. Gerar pacote de produção
npm run build
```
